# Weak Prompt (baseline)

An example of a vague prompt, used as the baseline for comparison.

```text
Make an employee API in Django.
```

## What is missing from this prompt
- No role or expertise level for the AI
- No fields, endpoints or validation rules
- No technology details (DRF? which database?)
- No error-handling expectations
- No request for tests or explanation
- No working process (plan first? step by step?)

## Likely gaps in the response (hypotheses to check)
- [ ] Guesses at the fields and endpoints
- [ ] Little or no input validation
- [ ] No automated tests
- [ ] Little explanation for a beginner
